## The challenge

Keep English and Spanish resumes maintainable without manually rebuilding each document after an update.

## My contribution

- Organized resume content in English and Spanish JSON files.
- Implemented HTML generation and PDF export commands for both languages.
- Added print styling and layout adjustments for the exported documents.

## Engineering decisions

- JSON Resume content is rendered with a portfolio theme.
- Puppeteer loads the generated HTML, applies print CSS and exports the PDF.
- Each language has explicit generation commands and its own source content.

## Outcome

A personal maintenance tool used for my resumes. The portfolio’s CV buttons link to the current PDFs supplied for this redesign.
