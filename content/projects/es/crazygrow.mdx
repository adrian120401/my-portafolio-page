## El desafío

Dar a un comercio un canal de venta online y las herramientas para administrarlo. La tienda pública y la administración privada deben conectarse alrededor de productos, disponibilidad y pedidos.

## Mi aporte

- Construí la experiencia de e-commerce para clientes.
- Desarrollé la plataforma administrativa para productos, inventario y pedidos.
- Conecté las interfaces con servicios backend y persistencia de datos.

## Decisiones técnicas

- Las interfaces React se conectan con un backend NestJS y una base PostgreSQL.
- La administración y la tienda son dos superficies del mismo sistema comercial.
- La entrega original utiliza Tailwind CSS e infraestructura Azure.

## Resultado

Una entrega para cliente que cubre la tienda pública y su administración operativa. Las dos entradas anteriores del portfolio ahora forman un caso único.
