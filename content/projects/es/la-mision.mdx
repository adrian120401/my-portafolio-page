## El desafío

Acompañar distintos momentos del recorrido de un participante: explorar circuitos, inscribirse y acceder a información de corredores. Las entregas resuelven flujos diferentes para un mismo cliente.

## Mi aporte

- Construí un sistema de inscripción con cuentas de usuario, validaciones y recuperación de contraseña.
- Integré PayPal, Mercado Pago y notificaciones automáticas por email.
- Desarrollé vistas de seguimiento e información con mapas interactivos y perfiles de elevación.
- La web pública actual de la carrera se incluye junto con inscripciones y seguimiento en este caso.

## Decisiones técnicas

- Inscripciones y seguimiento utilizan React, Node.js, Express y MySQL, según la documentación original de las entregas.
- React Leaflet permite explorar los circuitos. Las integraciones de pagos y correo acompañan el flujo de inscripción.
- La web pública y las aplicaciones operativas son entregas separadas; el stack indicado describe los sistemas de inscripción y seguimiento.

## Resultado

Las entregas relacionadas se presentan juntas para explicar el trabajo con el cliente sin contar el mismo producto como proyectos inconexos. La web actual enlaza información de circuitos e inscripciones.
