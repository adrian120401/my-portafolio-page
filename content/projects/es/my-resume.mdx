## El desafío

Mantener CVs en inglés y español sin reconstruir manualmente cada documento después de una actualización.

## Mi aporte

- Organicé el contenido del CV en archivos JSON en inglés y español.
- Implementé comandos de generación HTML y exportación PDF para ambos idiomas.
- Incorporé estilos de impresión y ajustes de layout para los documentos exportados.

## Decisiones técnicas

- El contenido JSON Resume se renderiza con un tema de portfolio.
- Puppeteer carga el HTML generado, aplica CSS de impresión y exporta el PDF.
- Cada idioma tiene comandos explícitos de generación y contenido fuente propio.

## Resultado

Una herramienta personal para mantener mis CVs. Los botones del portfolio enlazan los PDFs actuales proporcionados para este rediseño.
